A program that writes one funny single-line one-star review, written by a house cat about its human, to `/output/entry.txt`.

> "One star. He eats something different every night and calls it cooking. I get the same brown pellets and a lecture about routine."

Run with `node main.ts` (Node 22, no network at runtime).
